1.创建数据库

create {database|schema}[if not exists] 数据库名

[[default]character set 字符集名

|[default]collate 校对规则名

{}中的是选其中一个

[]是看情况写

create 是创建

database是数据库

MySQL 里：schema = database

if not exists 是如果有就不创建，但不报错，只警告

default 是指定默认值

字符集 charset	规定"哪些字符能存、每个占几字节"

排序规则 collation	规定"怎么比较、怎么排序"

chatacter set 是指定数据库字符集，后面的字符集名要用myspl支持的字符集名称代替，如gb2312

collate 是字符集的校对规则，后面的校对规则名要用myspl支持的校对规则名称代替，如gb2312_chinese_ci


最简单创建数据库的命令是：

2.打开数据库

3.修改数据库

[[default]character set 字符集名
|[default]collate 校对规则名]
